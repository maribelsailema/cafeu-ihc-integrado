# Checklist de Accesibilidad – CaféU 2.0

| Criterio                        | Cumple (Sí/No) | Observaciones                                                                 |
|---------------------------------|----------------|-------------------------------------------------------------------------------|
| Navegación completa por teclado | Sí             | Se puede recorrer catálogo, carrito y confirmación con Tab y Enter.           |
| Foco visible                    | Parcial        | El foco es visible en la mayoría de controles; en algunos botones del carrito es tenue. |
| Contraste adecuado              | Sí             | Textos principales y botones cumplen contraste WCAG AA.                       |
| Etiquetas en controles          | Sí             | Botones de cantidad (+ / –) y acciones principales tienen etiquetas claras.   |
| Mensajes de error claros        | Sí             | Se muestran mensajes al intentar confirmar pedido vacío o cantidades inválidas. |
| HTML semántico                  | Sí             | Uso correcto de header, main, section, button y roles apropiados.             |
| Textos alternativos             | Sí             | Imágenes de productos incluyen atributo alt.                                  |

**Resumen de problemas de accesibilidad encontrados:**
- Foco de teclado poco contrastado en algunos botones del carrito (menor).
- No se detectaron bloqueos de navegación por teclado.
