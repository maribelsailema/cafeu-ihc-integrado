# Análisis de Experiencia de Usuario - CaféU 2.0

## 1. Persona usuaria

**Nombre:** Estudiante universitario promedio  
**Edad:** 18-25 años  
**Contexto:** Estudiante de la Universidad Técnica de Ambato que utiliza la cafetería durante los recesos entre clases. Dispone de poco tiempo, usa principalmente el teléfono móvil y necesita realizar pedidos de forma rápida y sin errores.

**Objetivos:**
- Consultar productos disponibles
- Realizar pedidos de forma rápida
- Modificar o cancelar pedidos si es necesario
- Recibir confirmación clara del pedido

**Frustraciones actuales:**
- Dificultad para ver mensajes del sistema
- Problemas al seleccionar cantidades
- Búsqueda de productos poco efectiva
- Eliminación accidental de productos
- Dificultad para recuperar errores

## 2. Contexto de interacción

La interacción ocurre principalmente en el campus, entre clases, con tiempo limitado (5-10 minutos). El dispositivo principal es el teléfono móvil. La conexión puede ser inestable. El usuario necesita completar el pedido de forma eficiente y con mínima carga cognitiva.

## 3. Touchpoints (mínimo 5)

1. Ingreso a la aplicación
2. Búsqueda / consulta de productos
3. Selección de producto y cantidad
4. Visualización y gestión del carrito
5. Confirmación del pedido
6. Recepción de mensaje de confirmación / error

## 4. Momentos de verdad (mínimo 2)

1. **Momento de verdad 1:** Cuando el usuario intenta agregar un producto al carrito y debe seleccionar la cantidad correctamente.
2. **Momento de verdad 2:** Cuando el usuario elimina un producto por error y necesita recuperarlo o confirmar la acción.

## 5. Curva emocional

| Etapa                        | Emoción esperada     | Descripción                                      |
|-----------------------------|----------------------|--------------------------------------------------|
| Ingreso a la app            | Neutral / Esperanza  | El usuario espera encontrar lo que necesita rápido |
| Búsqueda de producto        | Frustración          | Si la búsqueda no tolera tildes o mayúsculas     |
| Selección de cantidad       | Confusión            | Dificultad para indicar la cantidad correcta     |
| Agregar al carrito          | Satisfacción         | Si el proceso es claro                           |
| Eliminación accidental      | Ansiedad / Enfado    | Pérdida de control al eliminar sin confirmación  |
| Recuperación de error       | Alivio / Frustración | Dependiendo de si el sistema permite recuperar   |
| Confirmación del pedido     | Satisfacción         | Si el mensaje es visible y claro                 |

## 6. Relación de problemas con principios de Nielsen y Gestalt

| Problema detectado                  | Principio Nielsen                          | Principio Gestalt                  |
|-------------------------------------|--------------------------------------------|------------------------------------|
| Visibilidad de mensajes             | Visibilidad del estado del sistema         | Figura-fondo                       |
| Selección de cantidades             | Control y libertad del usuario             | Proximidad                         |
| Búsqueda de productos               | Flexibilidad y eficiencia de uso           | Similitud                          |
| Eliminación accidental              | Prevención de errores                      | Cierre                             |
| Recuperación de errores             | Ayuda a los usuarios a reconocer, diagnosticar y recuperarse de errores | Continuidad |
