| Evidencia / flujo | Hallazgo o criterio | Implementación |
|---|---|---|
| Inicio → Ver Menú | H-05 / C-05 | CTA principal; búsqueda funcional |
| Menú y barra inferior | H-01 / C-01 | Acceso superior y barra flotante |
| Añadir producto | H-02 / C-02 | Contador, total y toast |
| Tarjeta → Detalle | H-04 / C-04 | Ver opciones y Personalizable |

La matriz APE6 indica que H-06 a H-12 no tienen confirmación de usuarios y varios dependen de validar la versión vigente. La tabla muestra cobertura técnica del prototipo de implementación, no una re-clasificación de los hallazgos.
